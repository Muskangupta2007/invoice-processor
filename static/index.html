Google Sheets Sync Setup Guide

  1. Create a new Google Sheet for your company.
  2. Add three sheets (tabs) named exactly: Invoices, Delivery Challans, and Pending MRNs.
  3. From the top menu, go to Extensions → Apps Script.
  4. Delete any code in the editor, copy the script snippet below, and paste it into the editor.
  5. Click Save (floppy icon) and rename the project to InvoSync Sync Service.
  6. Click Deploy (top-right) → New deployment.
  7. Click the gear icon next to "Select type", and select Web app.
  8. Configure deployment settings:
    • Execute as: Me (your email)
    • Who has access: Anyone
  9. Click Deploy. Grant permissions and click through warnings (Advanced → Go to project).
  10. Copy the generated Web App URL (ends in /exec) and paste it into the "Sync Web App URL" field for the corresponding company below.
